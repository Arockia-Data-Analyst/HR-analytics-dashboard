# 📊 HR Analytics Dashboard

An end-to-end **HR Analytics Project** developed using **Power BI** and **Streamlit** to analyze employee attrition and workforce trends through interactive dashboards and business insights.

---

# 📌 Project Overview

This project focuses on analyzing HR data to understand employee attrition, workforce demographics, salary distribution, and department-wise performance.

The dashboard helps HR professionals identify trends and make data-driven decisions to improve employee retention and workforce planning.

---

# 🎯 Project Objectives

- Analyze employee attrition
- Identify departments with high employee turnover
- Understand employee demographics
- Analyze salary distribution across job roles
- Study age-wise employee distribution
- Build an interactive HR dashboard
- Deploy the project as a Streamlit web application

# 📂 Dataset

The HR Analytics dataset contains employee information including:

- Employee ID
- Department
- Job Role
- Gender
- Age
- Monthly Income
- Attrition
- Education
- Business Travel
- Years at Company

---

# 🧹 Data Validation

Before building the dashboard, the dataset was validated.

Validation steps included:

- Checking for missing values
- Checking duplicate records
- Verifying data types
- Preparing the dataset for dashboard analysis

✅ No missing values were found.

✅ No duplicate records were found.

# 📊 Dashboard Features

The HR Analytics Dashboard includes:

- KPI Cards
- Employee Attrition Analysis
- Department-wise Attrition
- Gender-wise Attrition
- Age Distribution
- Salary Analysis
- Interactive Filters
- Employee Insights

---

# 📈 Key Performance Indicators

The dashboard displays:

- Total Employees
- Employees Left
- Average Monthly Income
- Average Employee Age

These KPIs provide a quick overview of workforce performance.

---

# 💡 Key Business Insights

- Research & Development department has the highest employee attrition.
- Sales department has the second-highest attrition.
- Most employees belong to the 30–40 years age group.
- Managers and Research Directors receive the highest average salaries.
- Interactive filters allow department and gender-wise analysis.
